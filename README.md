# Statistical_tests
Bundle of statistical tests for massive data

Following the decision tree of statistical tree

Decision tree:
Data -> dependent samples
     -> independent samples -> categorical : Chisq test, binominal test
                            -> continuous -> non-normal
                                          -> normally distributed (Shapiro-test) 
                                                  -> equal variance: t-test
                                                  -> unequal variance: Welch-test

Statistical tests were run to score the traits and genotypes of samples
